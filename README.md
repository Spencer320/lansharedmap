# Lan Shared Map

局域网和集成服务器共用的战争迷雾世界地图。走过的地表记在**服务器**上，同一世界里的其他人打开地图就能看到，不用各自再走一遍。

这是原创模组，不是 Xaero's World Map 的移植，也没有使用它的代码或材质。

## 下载

从 [Releases](https://github.com/Spencer320/lansharedmap/releases) 下载 `lansharedmap-1.1.0.jar`。

## 要求

- Minecraft **26.3**
- Fabric Loader **0.19.5**
- 适用于 Minecraft 26.3 的 Fabric API

## 安装

**主机**和**每一个客户端**都要装上同一份 jar。

1. 使用 Minecraft 26.3，安装 Fabric Loader 0.19.5，并装上适用于 26.3 的 Fabric API。
2. 把 Releases 里的模组 jar 放进 `mods/`。
3. 开世界的人（集成服务器或独立服务器）以及所有加入的玩家都要这样做。

只装在自己的客户端上时，服务器不会记录探索，地图会一直停在等待提示。

## 局域网

1. 一个人用装好模组的客户端打开世界（单人世界即可），或把 jar 放进独立服务器的 `mods/`。
2. 集成服务器：暂停菜单里选择**对局域网开放**。独立服务器：其他人加入同一地址。
3. 其他人也用装了同一模组的客户端加入。
4. 任意玩家走动。按 **M** 打开地图，同一维度里别人已经走过的地方会直接显示。

## 键位

默认键位可以在 **选项 → 控制 → 局域网共享地图** 里修改。

| 操作 | 默认 |
| --- | --- |
| 打开 / 关闭地图 | **M** |
| 平移 | 在地图上按住左键或中键拖拽 |
| 缩放 | 滚轮；右下角 `+` / `-` 以地图中心缩放 |
| 回到自己并继续跟随 | **C**，或右下角「居中」 |
| 添加路点 | 右键地图 |
| 删除附近路点 | Shift + 右键标记附近 |
| 关闭 | Esc，或再按一次 **M** |

打开地图时不会暂停集成服务器。路点只保存在本机，不会同步给其他玩家。
