# Lan Shared Map

局域网 / 集成服务器共用的战争迷雾世界地图。玩家走过的地表会记在**服务器**上，同一世界里的其他人打开地图时能直接看到，而不是只有自己的脚印。

这不是 Xaero's World Map 的移植，也没有使用它的代码或材质。

## 构建

需要 JDK 25。

```shell
./gradlew build
```

产物：

- `build/libs/lansharedmap-1.1.0.jar` — 放进 `mods/` 的文件
- `build/libs/lansharedmap-1.1.0-sources.jar` — 源码包

开发环境进游戏：

```shell
./gradlew runClient
```

## 安装

主机和**每一个**客户端都要装同一套：

1. Minecraft **26.3**
2. Fabric Loader **0.19.5**
3. Fabric API **0.162.0+26.3**
4. 本模组 jar

只装在客户端上时，服务器不会记录、也不会下发探索数据，地图会一直停在等待提示。

## 局域网怎么一起看地图

1. 一个人用 Fabric 客户端打开世界（单人集成服务器即可），或把 jar 放到独立服务器的 `mods/`。
2. 集成服务器：暂停菜单 → **对局域网开放**。独立服务器：其他玩家加入同一地址。
3. 其他人用装了同样模组的客户端加入。
4. 任意玩家走动。服务器按玩家所在区块周围 Chebyshev 距离 **3**（大约 7×7 个区块）记录已加载区块的地表颜色。
5. 加入时会收到整张地图的快照；之后新点亮的区块以增量包发给所有装了模组的玩家。
6. 按 **M** 打开全屏地图。同维度里别人已经走过的区域会直接显示，不用自己再走一遍。

探索数据由服务器根据玩家位置写入，客户端不能自行上报区块，避免随便点亮别人的地图。

## 键位

默认键位可以在 **选项 → 控制 → 局域网共享地图** 里改。

| 操作 | 默认 |
| --- | --- |
| 打开 / 关闭世界地图 | **M** |
| 平移 | 地图上按住**左键或中键**拖拽（会取消跟随）。点按钮不会开始拖地图 |
| 缩放 | 滚轮朝光标连续缩放（约 0.4%–1200%，100% = 每格 4 像素）。右下角 `+` / `-` 以地图中心为锚、步进更小。放大到 1 像素/格以上时按方块原色绘制，不再糊成一块 |
| 回到自己并继续跟随 | **C**，或右下角「居中」 |
| 添加路点 | 右键地图。出现橙色旗帜、底点，以及名字（缩得太远时只留标记） |
| 删除附近路点 | Shift + 右键标记附近（大约 22 像素内） |
| 关闭 | Esc，或再按一次 M |

地图打开时**不会暂停**集成服务器，方便局域网里其他人继续走动。

同维度的在线玩家画成朝向箭头（自己是金色）。右侧列表也会标出其他维度的人，但不会把他们画到当前地图上。光标下的方块坐标显示在指针旁和顶栏；右上角是相对默认视野的缩放百分比。区块大约宽过 14 像素时出现区块网格，单格大约 10 像素以上时再加方块网格。

## 路点

路点是可选的，只存在**本机**，不会同步给其他玩家。文件在：

`config/lansharedmap/<世界名与种子的哈希>.json`

世界 id 由服务器用「世界名 + 种子」发给客户端，用来区分不同存档。

## 存档

每个维度一份 Saved Data，id 为 `lansharedmap:explored`。26.3 把它写成：

`<维度数据目录>/lansharedmap/explored.dat`

主世界一般是存档里的 `data/lansharedmap/explored.dat`。下界、末地在各自维度目录的 `data/lansharedmap/explored.dat`。跟随世界自动保存，不需要额外导出。

## 包

| 方向 | id | 作用 |
| --- | --- | --- |
| S2C | `lansharedmap:map_hello` | 进服或重新要快照时清空客户端缓存，并带上世界 id |
| S2C | `lansharedmap:map_chunks` | 快照分批，或探索增量。每批最多 20 个区块 |
| S2C | `lansharedmap:player_positions` | 每 10 tick 刷新在线玩家位置 |
| C2S | `lansharedmap:request_snapshot` | 打开地图时如果还没收到 hello，再要一次快照 |

## 代码结构

- `dev.lansharedmap.network` — 自定义 payload 与注册
- `dev.lansharedmap.map` — 服务器探索记录、地表采样、`SavedData`
- `dev.lansharedmap.client` — 键位、客户端缓存、路点文件
- `dev.lansharedmap.client.screen` — 全屏地图

## v1 限制

- 采样 `WORLD_SURFACE` 上每一格的颜色：草方块用生物群系草颜色，树叶用树叶颜色，植物在树叶色和方块地图色之间混合，水用生物群系水色并按水深变暗，其余方块用 `MapColor`。明暗看北侧邻列的高度差，用来读出坡面。没有洞穴层，没有实体雷达，没有小地图 HUD。
- 颜色算法版本记在存档里（`v`）。玩家走到已经点亮、但还是旧颜色的区块旁边时，服务器会按当前算法重采样并同步，每名玩家每 tick 仍最多 6 个区块。没人再走近的旧区块会保持原样。
- 区块重采样之后，颜色再次固定。之后挖掉或铺上的方块不会继续刷新。
- 旁观者模式不会点亮地图。创造、生存会。
- 只点亮玩家周围约 7×7 个已加载区块，不是整个视距。想看更远的地方需要走过去。
- 每个玩家每 tick 最多新采样 6 个区块，避免一下子扫太多列。
- 不做跨服账号同步。路点不同步。
- 独立服务器和集成服务器都要装这个模组；原版客户端会被跳过，不会收到这些包。
